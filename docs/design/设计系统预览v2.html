✨ 微交互与细节

· 列表进入：fade + scale（0.96→1.0），220ms FastOutSlowIn
· Switch：Track 颜色与 Thumb 位移同步，120ms 过渡
· 一键视频：按下 scale 0.96，抬起回弹
· FAB：悬停 elevation 提升；空态呼吸式 scale（1.0↔1.06）
· 删除确认：Material3 AlertDialog，危险操作使用 tertiary 色按钮
· 高级感：深色底＋低饱和紫/青点缀，微圆角＋柔和阴影＋表面色阶，无装饰性动效

本预览覆盖：① 联系人列表（三态：加载 / 空态 / 列表，含 48dp 渐变头像 + 一键视频 + 快捷 Switch + 编辑 + FAB + 3 Tab 导航）｜ ② 添加/编辑（全屏无底栏，8 色头像选择器，56dp 保存）｜ ③ 保活设置（完成度概览 + 分组权限行 + 校准入口 → 8 步校准 Overlay）｜ ④ 关于（启动图标 + 版本 + 变更日志）｜ ⑤ 桌面快捷方式（8 色 + 绿色摄像机徽标，圆形 / Adaptive 两种）＋ ⑥ 软件启动图标（Adaptive Icon，多密度）。

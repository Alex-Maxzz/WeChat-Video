# 按键位置校准 · 悬浮窗 UI 设计规范

> 基于项目 `3(WXdianhua)`（老人微信视频电话 · `com.elder.wechatvideo`）现有 UI 风格与设计规范，对「按键位置校准」悬浮窗做的品牌一致性重做方案。
> 配套可视化预览：`校准悬浮窗预览.html`（可交互，覆盖 10 步 + 完成态）。

## 修订记录
- **v3（当前）**：按确认方向落地——**高斯模糊只用在步骤面板**，且改为**居中悬浮玻璃胶囊**（274px 宽、白/靛 58% + `blur(18px)`、顶部渐变点睛线 + 5px 十段进度细线）；标记层改为**轻透**（遮罩 10% + 微模糊 `blur(4px)`）、落点挖洞透光、不重模糊；取消做成**右上角独立红色小圆浮标**。整体体积更小、留白更多。
- **v2**：毛玻璃 + 紧凑（整层玻璃、引导条/底栏胶囊化）。被反馈"应只糊步骤面板、还要更小更有美感"迭代为 v3。
- **v1**：初版实心白卡 + 大面板（已被反馈"太大、不够玻璃感"推翻视觉形态，问题清单 P1–P7 / O1–O4 仍有效）。

## 1. 悬浮窗覆盖十个校准步骤（进度指示 + 操作引导）

悬浮窗采用「**常驻顶栏 + 阶段面板 + 标记层 + 底部确认栏**」四层结构，10 步交替为「引导 / 标记」两类形态：

| 步 | 阶段 | 操作引导（用户动作） | 推进方式 |
|----|------|----------------------|----------|
| ① | 引导 | 进入任意聊天对话 | 点「我已进入聊天」 |
| ② | 标记 | 点屏幕上「+」号按钮位置 | 底部「确认位置」 |
| ③ | 引导 | 手动点「+」打开功能面板 | 点「面板已打开」 |
| ④ | 标记 | 点面板中「视频通话」图标位置 | 底部「确认位置」 |
| ⑤ | 引导 | 手动点「视频通话」打开选择菜单 | 点「菜单已出现」 |
| ⑥ | 标记 | 点菜单中「视频通话」选项位置 | 底部「确认位置」 |
| ⑦ | 引导 | 返回微信首页 | 点「我已回到首页」 |
| ⑧ | 标记 | 点顶部「搜索」按钮位置 | 底部「确认位置」 |
| ⑨ | 引导 | 搜索并让【联系人】列表出现 | 点「结果已出现」 |
| ⑩ | 标记 | 点【联系人结果行】位置（兜底） | 底部「确认位置」→ 完成 |

**进度指示**：
- 常驻顶栏渐变徽标「步骤 X / 10」；
- 顶栏下方 **10 段步进器**：已完成=靛蓝实心，当前=蓝绿脉冲环，未到=浅灰；
- 阶段胶囊「引导 / 标记」用颜色区分（靛蓝 / 蓝绿），让用户理解交互为何切换。

**操作引导**：每步说明 17sp 加粗 + 灰色补充说明；标记步底部栏明确写出要点的按钮名（如「+号按钮」「搜索按钮」），避免老人猜。

## 2. 预览 UI 设计方案

### 2.1 布局结构（v3 居中玻璃胶囊 · 轻透标记层）
```
              ┌─ 取消浮标（右上角红圆 ✕，常驻）─┐
              └────────────────────────────────┘
        ┌─ 步骤面板：居中悬浮玻璃胶囊（仅引导步）─┐
        │  ── 3px 品牌渐变点睛线 ──                │
        │  ▁▁▁▁▁▁▁▁▁▁▁ 5px 十段进度（靛/蓝绿）      │
        │ [步骤 X/10]        [引导/标记]           │
        │ 说明(14.5sp)+灰字补充                     │
        │ [上一步]          [下一步/我已进入聊天]   │  ← 高42dp
        └─────────────────────────────────────────┘
   （标记步：隐藏胶囊，改为下方）
        ┌─ 全屏标记层（轻透 blur(4px) 10%遮罩）──┐
        │  微模糊微信 · 落点径向挖洞(64px)透光      │
        │  ◉ 蓝绿标记环+红点+白十字+坐标气泡        │
        │  ┌─ 底部确认胶囊（仅标记步，居中）────┐  │
        │  │ 提示：点击屏幕上【+号按钮】的位置   │  │
        │  │ [重新点选]            [确认位置]    │  │
        │  └──────────────────────────────────┘  │
        └─────────────────────────────────────────┘
   完成态：蓝绿对勾玻璃卡（已存5点+测试一次+返回应用）
```

### 2.2 控件排列
- **常驻顶栏**：左标题+进度徽标，中阶段胶囊，右取消（40×40 圆形红，≥48dp 触控）。
- **引导面板**：拖拽握把 → 步骤说明 → 「上一步」(靛蓝描边) +「下一步」(靛蓝渐变)，最小高 52dp。
- **标记层**：遮罩保证微信可读；标记点=蓝绿圆环+红精确点+白十字+坐标气泡。
- **底部确认栏**：提示行（写明按钮名）→「重新点选」(琥珀描边)+「确认位置」(蓝绿实心)；可拖动避让底部按钮。

### 2.3 配色方案（Design Tokens，与 App 一致）
| 用途 | 色值 | 说明 |
|------|------|------|
| 主操作 / 下一步 | 靛蓝渐变 `#5B53E0→#3a33a0` | 白字，匹配 App 呼叫按钮 |
| 成功 / 标记环 / 确认 | 蓝绿 `#10B59A` | 匹配视频徽标 |
| 警示 / 重选 | 琥珀 `#E0851C` | 替代原 `#FF9800` |
| 取消 / 危险 | 红 `#E5484D` | 替代原灰 `#757575`，呼应版本文档「红色取消」 |
| 面板（步骤面板） | 白/靛 **58%** + `backdrop-filter:blur(18px)` 毛玻璃 + 白边 + 柔影 + 顶部渐变点睛线 | 高斯模糊只作用于步骤面板，透光有质感、文字清晰 |
| 遮罩（标记步） | 深靛 `rgba(38,34,66,.10)` + `blur(4px)` 微模糊，落点径向挖洞透光 | 轻透不重糊，便于看清并点中微信按钮 |
| 字号 | 说明 14.5sp / 步骤 11sp / 按钮 13.5sp | 收一档但仍清晰（紧凑优先） |

### 2.4 交互逻辑（状态机）
- **引导步**：显示顶栏+步进器+引导面板，隐藏标记层/底栏；用户完成微信操作后点「下一步」推进。
- **标记步**：显示顶栏+步进器+遮罩+标记点+底栏，隐藏引导面板；点屏生成标记→「确认位置」存坐标并推进，「重新点选」清除重来。
- **任意步**：红色「✕ 取消」常驻；引导步额外「上一步」回退。
- **完成**：隐藏所有浮层，显示蓝绿完成卡（已存 5 点 + 测试一次 + 返回应用）；坐标仅作折叠详情，不直面老人。

## 3. 设计建议（用户体验优化 + 潜在问题）

### 潜在问题（按严重度）
1. **P1 颜色割裂（高）**：悬浮窗/标记层用 Material 默认色，与品牌脱节。→ 全部替换为本规范令牌。
2. **P2 标记步无法取消（高）**：现有实现标记步 `guideBarView.GONE` 且取消隐藏，用户卡住只能强杀。→ 取消提至常驻顶栏。
3. **P3 无返回纠错（中）**：误点「下一步」不可回退。→ 加「上一步」。
4. **P4 文案过时（中）**：`strings.xml` 校准说明仍「共 8 步」，实际已 10 步（⑨⑩搜索结果行兜底）。→ 同步更新。
5. **P5 无进度可视（中）**：仅文字「步骤 X/10」。→ 加 10 段步进器。
6. **P6 引导栏遮挡（中）**：版本文档要求可拖动避让（尤其第 9 步不挡搜索按钮），但 `createGuideBar` 未见拖动实现。→ 补 OnTouchListener + 握把暗示。
7. **P7 占位按钮迷惑（低）**：标记步主按钮文案「（使用底部按钮确认）」且置空。→ 标记步直接隐藏引导面板主按钮。

### 体验优化方向
- **O1 完成页对老人友好**：现有 `showCalibrationSummary` 直接打印坐标 → 改为蓝绿对勾 + 一句话 + 可折叠「高级详情」。
- **O2 标记更精准**：遮罩降至 34%、环用蓝绿、中心点保留红，兼顾品牌与精度。
- **O3 容错提示**：确认前未点选弹 Toast；坐标异常（落状态栏等）提示重选，防存错点。
- **O4 微信升级联动**：`WeChatVersionDetector` 已在校准完成存版本号，可在完成卡加「微信版本已记录」，升级后快捷方式拦截提示「建议重新校准」，增强信任。

- **范围**：本方案全部产出仅写入 `4-WXdianhua-v2/UI设计预览/按键位置校准UI/`（本预览 HTML + 本规范）。`3(WXdianhua)` 工程**仅读取、零修改**。
